# Retro Adda

Free, no-login retro browser games (static site, no build step).

- Games: Snake, 2048, Memory Match, Tic-Tac-Toe, Minesweeper, Brick Buster, Flap Hop.
- Ads: paste the Monetag snippet into `js/ad-config.js` (inside the backticks in `monetagSnippet`). Empty = no ad code runs and ad spaces stay hidden.
- Deploy: static files at the repo root; Vercel serves them with no build.
